# JS Challenges

Repositorio de retos de JavaScript enfocado en practicar lógica, estructuras de datos y resolución de problemas con ejercicios cortos y directos.

Cada reto incluye su enunciado, reglas y, cuando aplica, una solución de referencia para comparar enfoques y practicar buenas prácticas en JavaScript.

## Contenido

- Retos de programación en JavaScript
- Enunciados claros y ejemplos de uso
- Soluciones de referencia en algunos ejercicios
